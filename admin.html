Conexión y carga

El panel lee el index.html publicado, te deja editar cada texto, enlace y componente, y al publicar crea un Pull Request en GitHub con el archivo actualizado. Los cambios se guardan como borrador en este navegador mientras trabajas.

Crea un token fine-grained en github.com/settings/tokens con acceso solo a este repositorio y permisos "Contents: Read and write" y "Pull requests: Read and write". Se guarda únicamente en este navegador y solo se envía a api.github.com; no lo uses en un equipo compartido.
