Panel de contenido del sitio

Edita el contenido de index.html por secciones, igual que están organizadas en el sitio. Al aplicar los cambios se crea automáticamente un Pull Request en el repositorio para publicarlos.

0. Conexión con GitHub

Crea un token de acceso personal (fine-grained) en github.com/settings/tokens, con acceso limitado a este repositorio y permisos de "Contents: Read and write" y "Pull requests: Read and write". El token se guarda solo en este navegador (localStorage) y se envía únicamente a api.github.com; no lo compartas ni lo uses en un equipo público.

Si abres este panel directamente desde tu computador (file://) el navegador puede bloquear la carga automática; en ese caso usa "Cargar desde archivo…" y selecciona tu index.html. Si lo abres desde el sitio publicado, "Cargar contenido actual" funciona directo.

Aún no se ha cargado ningún contenido. Usa "Cargar contenido actual" o "Cargar desde archivo…" arriba antes de editar.

Experience

Agrega, edita, elimina o reordena (↑/↓) puestos de trabajo. Corresponden a la tabla "Experiencia" del sitio. Si dejas la descripción vacía, la fila se muestra sin desplegable.

Estudios

Agrega, edita, elimina o reordena (↑/↓) cursos, títulos o certificaciones. Corresponden a "Formación y certificaciones" del sitio.

Servicios

Agrega, edita, elimina o reordena (↑/↓) los servicios que se muestran en la sección "Servicios". Cada texto tiene versión en inglés (EN) y en español (ES).

Portfolio

Agrega, edita, elimina o reordena (↑/↓) proyectos del portafolio. La categoría controla los filtros del sitio: usa una o más de estas palabras separadas por espacio — delivery, public, ai, community.

Testimonios

Agrega, edita, elimina o reordena (↑/↓) testimonios de clientes.

Blog

Agrega, edita, elimina o reordena (↑/↓) publicaciones del blog.

Menú — Orden de los enlaces

Reordena (↑/↓) o edita el texto de los enlaces del menú del menú superior. Cada uno sigue apuntando a su sección real del sitio; no se pueden agregar ni quitar enlaces aquí.

Guardar cambios

"Aplicar y crear Pull Request" actualiza la vista previa y, tras confirmar, crea una rama nueva en GitHub con estos cambios (de todas las pestañas) y abre un Pull Request contra la rama base para revisarlos antes de publicarlos. "Descargar" sigue disponible como respaldo manual si prefieres subir el archivo tú misma.
